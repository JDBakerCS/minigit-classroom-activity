# Activity 7 Student Worksheet

## Worked example

UN:

> A student needs a way to submit the correct assignment because sending the wrong file may result in lost credit.

Ask four questions:

1. What must the student **see**? Available files and the selected file.
2. What must the student **choose**? The file to submit.
3. What must the student **do**? Submit the selected file.
4. What must the student **confirm**? That the intended file was received.

Derived atomic URs:

- A student shall be able to select a file for submission.
- A student shall be able to review the selected filename before submission.
- A student shall be able to submit the selected file.
- A student shall be able to receive confirmation identifying the submitted file.

Each UR contains one main capability. Together they support the need.
