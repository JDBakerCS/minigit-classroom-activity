# Activity 6 Student Worksheet

## Worked example

Candidate need:

> A traveler needs a way to know tomorrow’s weather because unsafe conditions may affect travel plans.

Different possible solutions:

1. A weather app displays a forecast.
2. A telephone service reads the forecast aloud.
3. A public display shows a weather warning.

All three satisfy the same outcome, so the need is **solution-independent**. It does not require an app, screen, button, or programming language.

Use this test:

> Can two or more meaningfully different designs satisfy the statement without changing its wording?

If yes, it is probably solution-independent. If no, it probably contains a chosen solution.
