# Mini Git UN/UR Classroom Activities — Shortened Edition

This edition is designed for limited class time. Each activity folder contains an instructor guide, student worksheet, and answer key. Activities 1–7 may be used independently.

| Activity | Focus | Suggested time |
|---|---|---:|
| 1 | Combine two independently modified C++ files | 20 min |
| 2 | Connect five commands to goals and risks | 15 min |
| 3 | Use “why” questions for every command | 20 min |
| 4 | Separate observations from problems | 15 min |
| 5 | Build a complete derivation ladder | 25 min |
| 6 | Test solution independence | 15 min |
| 7 | Derive several URs from one UN | 20 min |

Core patterns:

- **UN:** A `[role]` needs a way to `[desired outcome]` because `[problem or reason]`.
- **UR:** A `[role]` shall be able to `[one user-visible capability]`.

The command set for Activities 2 and 3 is limited to `status`, `diff`, `add`, `commit`, and `log`.
